# Native SQL

sqala supports native SQL through the `sql` interpolator:

```scala
import sqala.jdbc.sql

val x = 1
val y = "abc"

val nativeSql = sql"select * from t where x = $x and y = $y"
```

Interpolated arguments are encoded at compile time through the `JdbcEncoder` type class: a scalar argument needs a `JdbcEncoder` for its own type, while a `Seq` argument needs a `JdbcEncoder` for its **element type** (no encoder instance is required for the `Seq` itself). Instances for built-in types are provided, and custom types can define their own. A `Seq` argument is expanded into `(?, ?, ?)`, which is convenient for `IN` clauses; the compiler does not inspect the `Seq` contents, so passing an empty `Seq` still compiles but throws `IllegalArgumentException` at execution time.

Note that `JdbcEncoder` only affects native SQL parameter binding. Values in the query DSL are converted by `AsSqlExpr`; the DSL does not use `JdbcEncoder`, so a custom `JdbcEncoder` does not change the SQL or parameters generated by the DSL.

The `sql` interpolator supports the `+` operator, which makes it easy to compose SQL conditionally:

```scala
import sqala.jdbc.sql

val x = 1
val y = "abc"

var nativeSql = sql"select * from t where true "

if x > 0 then nativeSql += sql"and x = $x "

if y.nonEmpty then nativeSql += sql"and y = $y"
```

Besides `NativeSql`, `+` also provides a `String` overload that appends raw SQL text. Note that the appended string goes directly into the SQL without any parameter binding, so ensuring its safety is the caller's responsibility:

```scala
val order = " order by x"

val sorted = nativeSql + order
```

Use the `fetchTo` method to execute native SQL queries:

```scala
case class Result(x: Int, y: String)

val result = db.fetchTo[Result](nativeSql)
```

If you do not want to define a case class for the result, use `fetchToMap` to read each row as a `Map[String, Any]`:

```scala
val result: List[Map[String, Any]] = db.fetchToMap(nativeSql)
```

For native DML such as INSERT/UPDATE/DELETE, use `db.execute`, which returns the number of affected rows:

```scala
val affected: Int = db.execute(sql"update t set y = $y where x = $x")
```
